## Erstmal die wichtigsten Wörter

- **Raid:** Eine Gruppe, die gemeinsam einen bestimmten Inhalt spielt.
- **Raid-Post:** Der Beitrag vom Bot mit Termin, freien Plätzen und Teilnehmern.
- **Slot:** Ein Platz in der Gruppe. `3 / 6` heißt: 3 Plätze sind belegt, 3 sind noch frei.
- **Organizer:** Die Person, die den Raid-Post erstellt hat.
- **Charakter-Emote:** Das Emote neben deinem Namen, damit alle sehen, mit welchem Charakter du mitkommst.
